# 🔐 PassGuard – Password Manager

PassGuard is a simple Python-based password manager that securely stores passwords using Fernet encryption.

### ✨ Features
- Add and save passwords.
- Encrypt passwords before storing.
- Decrypt and view saved passwords.
- Automatically generate an encryption key.

### 🛠️ Technologies
- Python
- Cryptography Library
- Fernet Encryption

### ⚙️ Installation

```bash
pip install cryptography
python main.py
```

### 🔒 Security
Passwords are encrypted before storage. Keep your `key.key` file private and never upload it to GitHub.
